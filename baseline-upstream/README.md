# ⛏️ WebCraft —— 网页版我的世界

一个完全运行在浏览器中的体素沙盒游戏复刻。无需安装、无需联网（除打开页面外），
包含程序化地形、树木、洞穴、水体、昼夜般的远景雾效、破坏与放置方块、飞行模式等玩法。

## 快速开始

直接用现代浏览器（Chrome / Edge 推荐）打开 `index.html` 即可：

```bash
# 或者启动一个本地静态服务器
python -m http.server 8080
# 然后访问 http://localhost:8080
```

点击「开始游戏」，鼠标会被锁定。按 `ESC` 释放鼠标。

## 操作说明

| 按键 | 功能 |
| --- | --- |
| `W A S D` | 移动 |
| `空格` | 跳跃 / 水中上浮 |
| `Shift` | 下蹲（减慢移动） / 飞行时下降 |
| 双击 `W` | 疾跑 |
| `F` | 切换飞行模式 |
| 鼠标左键 | 破坏准星指向的方块 |
| 鼠标右键 | 放置当前选中的方块 |
| `1 - 9` / 滚轮 | 选择快捷栏方块 |
| `ESC` | 释放鼠标 |

## 世界生成

- 使用种子随机数 + 多层柏林噪声生成起伏地形
- 海洋、沙滩、草地、雪山
- 橡树（原木 + 树叶）
- 3D 噪声侵蚀形成地下洞穴
- 基岩层、沙地海岸与水面

所有方块编辑都会自动保存到浏览器的 `localStorage`，
刷新页面后地形和建筑仍然保留。清除浏览器站点数据即可重置世界。

## 指定世界种子

在 URL 后添加 `?seed=12345` 可以生成相同的世界：

```
index.html?seed=12345
```

## 技术实现

- 纯前端：HTML + CSS + JavaScript + WebGL
- 渲染引擎：本地内置的 [Three.js r128](vendor/three.min.js)（不依赖 CDN）
- 体素世界：16×16×96 区块，按需生成、分帧构建、视距外卸载
- 网格优化：相邻面剔除 + 顶点环境光遮蔽（AO）
- 纹理：Canvas 程序化绘制的 16×16 像素风格图集
- 交互：Amanatides & Woo 体素射线检测（DDA）
- 物理：AABB 分轴碰撞、重力、跳跃、游泳、飞行

## 文件结构

```
index.html        页面结构与 UI
css/style.css     准星、快捷栏、开始菜单样式
js/noise.js       种子随机数、2D/3D 柏林噪声
js/blocks.js      方块定义、纹理图集生成
js/world.js       区块生成、网格构建、方块读写与存档
js/player.js      玩家移动与体素碰撞
js/main.js        渲染循环、输入、射线交互、HUD
vendor/           Three.js 运行库
```
