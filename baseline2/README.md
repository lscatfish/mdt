# WebCraft · 网页版我的世界

一个纯前端、零构建依赖的浏览器体素沙盒游戏：无限程序化世界、区块流式加载、
破坏 / 放置方块、第一人称物理、昼夜循环与本地存档。除 vendored 的 Three.js
（`three.min.js`）外没有任何外部资源，直接双击 `index.html` 即可游玩。

## 运行方式

**方式一（推荐，无需任何工具）**
直接用 Chrome / Edge / Firefox 打开 `index.html`。

**方式二（本地服务器，可选）**
```bash
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 已实现功能

- **无限世界**：基于种子的可复现地形（丘陵、山脉、海洋、沙滩、雪顶、洞穴）
- **生态植被**：树（原木 + 树叶）、红花、黄花、草丛
- **体素渲染**：逐面剔除网格、顶点环境光遮蔽（AO）、程序化 16×16 纹理图集
- **物理系统**：AABB 碰撞、重力、跳跃、游泳、创造飞行、疾跑
- **交互**：DDA 体素射线拾取、方块高亮、破坏 / 放置（含方块名快捷栏）
- **昼夜循环**：太阳 / 月亮 / 星空着色器、暮色染色、漂移云层
- **程序化音效**：破坏、放置、脚步、入水，全部由 WebAudio 合成
- **本地存档**：玩家修改过的区块自动保存到 `localStorage`（每 10 秒 + 关闭页面前）
- **调试面板**：`F3` 查看坐标、FPS、区块与绘制统计

## 项目结构

```
index.html          页面骨架与 HUD
css/style.css       界面样式
three.min.js        Three.js r128（本地 vendored）
js/noise.js         值噪声 / FBM / 山脊噪声
js/blocks.js        方块定义 + 程序化纹理图集
js/world.js         区块生成、网格构建、射线、存档
js/player.js        玩家物理与碰撞
js/controls.js      键鼠 + 触屏输入
js/audio.js         WebAudio 合成音效
js/sky.js           天空着色器与云层
js/hud.js           快捷栏 / 调试面板
js/main.js          游戏装配与主循环
```

## 技术说明

- 区块尺寸 16×128×16，渲染半径 5 区块；网格在帧预算内按距离优先级流式构建
- 光照为烘焙顶点 AO + 面亮度，材质使用 `MeshBasicMaterial`，无需动态光源
- 世界修改只保存脏区块（Base64），覆盖在确定性地形之上
- 存档键名 `webcraft-save-v1`；点开始界面的“新世界”可清空重来
