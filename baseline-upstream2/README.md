# ⛏ WebCraft —— 网页版我的世界

一个完全自包含的网页体素游戏：没有外部依赖，没有 CDN，没有图片/音频资源文件。用现代浏览器打开 `index.html` 即可游玩。

## 运行方式

1. 下载或克隆本项目；
2. 双击 `index.html`（推荐 Chrome / Edge / Firefox 最新版）；
3. 选择 **生存模式** 或 **创造模式** 开始游戏。

> 需要桌面浏览器和鼠标键盘。游戏会请求指针锁定（鼠标捕获），按 `Esc` 可暂停。

## 玩法与操作

| 按键 | 功能 |
| --- | --- |
| `W A S D` | 移动 |
| 鼠标 | 视角 |
| 左键 | 破坏方块（生存模式需长按） |
| 右键 | 放置方块 |
| `Space` | 跳跃 / 水中上浮 / 飞行上升 |
| `Shift` | 潜行 / 飞行下降 |
| `R` 或 `Ctrl` | 疾跑 |
| `1 - 0` / 滚轮 | 选择快捷栏方块 |
| `F` | 创造模式切换飞行 |
| `G` | 切换生存 / 创造模式 |
| `M` | 静音 / 取消静音 |
| `Esc` | 暂停 |

## 已实现特性

- 纯 WebGL 体素渲染（区块网格、面剔除、环境光遮蔽、雾效）
- 程序化无限地形：丘陵、山脉、海洋、沙滩、树木
- 10 种可放置方块：草、泥土、石头、圆石、木板、原木、树叶、沙子、玻璃、水
- 方块破坏 / 放置、DDA 体素射线检测、选中方块线框
- 生存模式：重力、碰撞、跳跃、疾跑、游泳、长按破坏
- 创造模式：飞行、瞬间破坏
- 昼夜循环、太阳 / 月亮 / 星空、动态云层
- 程序生成的像素纹理图集（16×16，无需外部贴图）
- 程序合成音效（Web Audio，无音频文件）
- 快捷栏、HUD、暂停菜单、模式切换
- 世界编辑与玩家状态自动保存到 `localStorage`，可继续上次游戏
- 不同种子生成不同世界（种子支持数字或任意文字）

## 技术说明

- 单文件 `index.html`，约 70 KB，包含 HTML/CSS/JavaScript；
- 世界高度 64 格，视距 4 个区块（64 格）；
- 地形使用多层值噪声 + fBm 生成；
- 区块网格采用不透明 / 透明两遍渲染，树叶与玻璃使用 alpha test，水体使用混合；
- 所有纹理在运行时用 Canvas 绘制到 128×128 图集，开启 mipmap。
