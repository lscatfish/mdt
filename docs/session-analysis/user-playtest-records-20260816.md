## RL（RL-open，anchored-standard-open 首跑，首轮官方 minimal [bash,str_replace_editor] + 一句 persona，step 2 晋升 63 全开）

**实测时间**：2026-08-16

**用户评价摘要**：该有的基本都有；**最大 bug = 方向键绑定世界坐标**（点前进不是前进，与视角不绑定）；玻璃太透明（透明到看不出是玻璃，但穿透渲染正常）。

### 具体观察

| 项目 | 结果 |
| --- | --- |
| 群系/内容 | ✅ 有湖、有水、有树，该有的基本都有 |
| 洞穴 | ❌ **没有洞穴** |
| 矿物 | ❌ **没有矿物** |
| 水 | ⚠️ 左键可以破坏；可以游泳 |
| 方向键 | ❌ **最大 bug：方向键绑定世界坐标系**——点"前进"并不是朝视角前进；需要转动视角；前进与世界系下固定的一个坐标绑定（与视角不绑定） |
| 玻璃 | ⚠️ **做得太透明**——透明到看不出来是玻璃；但**穿透渲染确实是正常的**（这点值得肯定） |

- 与综合报告评级"较好"一致（操作键的按键方向解算有问题、可游泳、未报水渲染问题）。
- 方向 bug 与思维链分析对应：方向解算的推导与实测都只在 yaw=0 退化点自洽（sin0=0 消掉交叉项误差），非零 yaw 的旋转顺序/符号从未被覆盖——用户实测确认了"前进与世界系绑定"的表现。
- 玻璃形态小结（截至 RL）：透视（B1/B+T）/ 正常（B2、PA）/ 全黑不透（UP）/ 太透明到看不出（RL）——穿透渲染正常的会话 = B2、PA、RL。
