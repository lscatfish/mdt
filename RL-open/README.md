# ⛏ WebCraft — 网页版我的世界

一个在浏览器中运行的体素沙盒游戏复刻。基于原生 JavaScript + Three.js，无需构建工具，所有方块纹理均为运行时程序化生成的像素画，不依赖任何外部图片资源。

## 快速开始

```bash
npm install
npm start
```

然后打开浏览器访问 <http://localhost:8000>（可用环境变量 `PORT` 修改端口）。

## 玩法特性

- **无限程序化世界**：种子随机生成，丘陵、山峰、沙滩、海洋与洞穴
- **区块流式加载**：以玩家为中心动态生成 / 卸载区块，只渲染可见面
- **方块交互**：鼠标左键破坏（按住连续）、右键放置，带 DDA 体素射线与选中高亮框
- **9 种可放置方块**：草方块、泥土、石头、圆石、沙子、原木、树叶、木板、玻璃
- **第一人称物理**：重力、跳跃、疾跑、AABB 体素碰撞、飞行模式
- **昼夜循环**：太阳 / 月亮、天空与雾颜色过渡、动态光照，以及飘动的云
- **自动存档**：破坏与放置记录保存在浏览器 localStorage，刷新后恢复
- **像素风纹理**：Canvas 程序化生成的 16×16 纹理图集

## 操作

| 输入 | 动作 |
| --- | --- |
| 鼠标移动 | 视角 |
| W A S D | 移动 |
| 空格 | 跳跃 / 飞行上升 |
| Shift | 疾跑 / 飞行下降 |
| 左键 / 右键 | 破坏 / 放置方块 |
| 1–9 或滚轮 | 选择方块 |
| F | 切换飞行模式 |
| R | 回到出生点 |
| Esc | 暂停 |

## 技术结构

```
├── server.mjs          # 零依赖静态文件服务器
├── index.html          # 页面与 HUD
├── style.css
└── src/
    ├── main.js         # 入口，连接 DOM 与游戏
    ├── game.js         # 渲染循环、区块流、昼夜、交互、存档
    ├── world.js        # 区块存储与程序化地形生成
    ├── mesher.js       # 区块网格构建（隐藏面剔除）
    ├── player.js       # 第一人称控制器与体素碰撞
    ├── noise.js        # 确定性 2D/3D 值噪声 + FBM
    └── blocks.js       # 方块定义与像素纹理图集
```

## 自定义世界种子

在开始菜单输入种子（如 `minecraft`），或通过 URL 保持同一世界：世界数据随存档保存，刷新页面即可继续。
