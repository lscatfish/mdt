# WebCraft — 网页版《我的世界》克隆

一个完全运行在浏览器中的体素沙盒游戏。**零外部依赖**：不使用任何库或 CDN，
渲染器、地形生成、纹理、音效全部由原生 JavaScript + WebGL 实现，打开 `index.html` 即可游玩。

## 快速开始

```bash
# 方式一：直接双击 index.html（无需服务器，完全离线可玩）
start index.html

# 方式二：任意静态服务器
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

点击 **进入游戏** 后鼠标会被锁定，按 `Esc` 暂停。

> 推荐使用桌面版 Chrome / Edge / Firefox。游戏依赖指针锁定 API；
> iOS Safari 等不支持指针锁定的环境只能停留在开始界面。

## 已实现特性

- **无限世界**：16×16×96 区块按玩家位置流式加载 / 卸载，Simplex 噪声地形
  （平原、丘陵、山脉、雪山、海洋、海滩）
- **地下世界**：3D 噪声洞穴、煤矿 / 铁矿 / 金矿 / 钻石矿、基岩层
- **植被**：按种子确定性生成的树木
- **方块系统**：19 种方块（草、泥土、石头、圆石、木板、原木、树叶、沙子、
  水、基岩、四种矿石、雪、玻璃、沙砾、砖块）
- **自定义 WebGL 渲染器**：程序化 16×16 像素纹理图集、逐面光照 +
  顶点环境光遮蔽（AO）、距离雾、天空穹顶与太阳、漂移的云层
- **半透明水面与玻璃**：独立渲染通道，水面高度略低于整格，水下抬头可见水面并带蓝色遮罩
- **第一人称物理**：AABB 碰撞（子步进防穿透）、重力、跳跃、游泳、
  创造模式飞行、疾跑、潜行
- **交互**：DDA 体素射线拾取、方块轮廓高亮、破坏粒子效果、按住连挖/连放
- **HUD**：十字准星、快捷栏（实时方块图标）、FPS、坐标、种子信息
- **音效**：WebAudio 程序化合成（破坏 / 放置 / 脚步）
- **存档**：所有方块修改自动保存到 `localStorage`，按世界种子确定性重建

## 项目结构

```
index.html        页面与 HUD 结构
styles.css        UI 样式
js/
  noise.js        带种子 Simplex 2D/3D 噪声、fBm、山脊噪声
  textures.js     程序化纹理图集与方块定义
  world.js        区块化世界、地形/洞穴/树木/矿石生成、编辑存档
  mesher.js       体素 -> 顶点数组（面剔除、AO、水面）
  renderer.js     WebGL 渲染器（着色器、天空、云、粒子、描边）
  player.js       输入管理与玩家物理
  audio.js        WebAudio 音效合成
  main.js         游戏循环、射线拾取、玩法逻辑
```

## 技术说明

- **零依赖**：所有着色器与矩阵运算均为手写，无构建步骤。
- **确定性生成**：同一个种子永远生成同一个世界，因此存档只需记录玩家
  修改的方块（区块压缩为 `[索引, 方块id]` 列表）。
- **渲染性能**：只构建暴露在空气中的面；区块网格在相邻区块就绪后才重建，
  边缘修改会连带更新相邻区块；每帧限制生成/重建预算避免卡顿。
