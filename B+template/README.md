# WebCraft · 网页版我的世界

一个纯前端（HTML + JavaScript + Three.js）实现的体素沙盒游戏，在浏览器中复刻 Minecraft 的核心体验。所有纹理均为程序化生成，无任何外部素材；运行不依赖构建工具，也不需要联网（Three.js 已本地化到 `vendor/`）。

## 运行

方式一（推荐，禁用缓存）：

```bash
python serve.py          # 默认 http://127.0.0.1:8133
python serve.py 8000     # 自定义端口
```

方式二：任意静态文件服务器，例如

```bash
python -m http.server 8000
# 或 npx serve .
```

浏览器打开对应地址，点击「开始游戏」即可。URL 可带 `?seed=12345` 指定世界种子。

### 已实现特性

- 程序化无限地形：草原、沙漠、森林、丘陵与山脉，含海岸沙滩、湖泊、洞穴与煤矿/铁矿
- 树木、原木与树叶的跨区块装饰生成
- 区块流式加载/卸载（16×64×16），远处区块按需生成与重建
- 可见面剔除 + 顶点环境光遮蔽（AO）+ 方向面明暗的体素网格
- 程序化 16×16 像素纹理图集（草、泥土、石头、圆石、沙子、原木、树叶、木板、矿石、基岩、水、玻璃）
- 第一人称 AABB 碰撞物理：重力、跳跃、疾跑、飞行、游泳浮力
- DDA 体素射线检测、准星方块高亮、破坏/放置（含基岩保护、放置不穿模）
- 天空穹顶渐变、太阳光晕、体积云、雾
- 10 格快捷栏与 2D 等距方块图标
- WebAudio 程序化音效（破坏/放置/跳跃/落水）
- 本地存档：修改过的区块自动保存到 localStorage，刷新后恢复
- 指针锁定不可用时的鼠标增量视角降级方案

## 实现要点

- 世界为纯函数式生成：地形只由世界种子决定，方块修改作为「编辑层」覆盖在生成结果之上，并以区块为单位持久化。
- 区块网格使用世界坐标顶点，区块分组原点固定；`matrixAutoUpdate` 关闭以减少每帧矩阵更新开销。
- AO 按面四个角分别采样两个侧邻居与对角邻居，遮蔽度映射为 4 档亮度；树叶不参与 AO 但参与面剔除。
- 物理采用 1/60s 固定步长逐轴积分，逐轴与体素 AABB 解碰撞，避免高速穿墙。
- 水面渲染：相邻水体之间剔除共享面，并在水面下方补绘底面，使水下抬头可见水面。
- 纹理图集使用 `CanvasTexture` 且 `flipY = false`，保证 UV 行号与图集行号一一对应。
