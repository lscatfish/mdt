# 网页版我的世界 · WebCraft

一个纯前端复刻的网页版 Minecraft 风格体素沙盒游戏：程序化无限地形、区块网格渲染、
第一人称物理、方块破坏/放置、昼夜循环与本地存档，全部代码与资源都在本目录内。

## 运行方式

直接用浏览器打开 `index.html` 即可（所有资源均为本地文件，不需要联网）：

```bash
# 或使用任意静态服务器
python -m http.server 8000
# 打开 http://127.0.0.1:8000
```

> 首次点击「创建新世界」后浏览器会请求鼠标指针锁定，选择“允许”即可开始。

## 玩法与操作

| 按键 | 功能 |
| --- | --- |
| `W A S D` / 方向键 | 移动 |
| 鼠标 | 转动视角 |
| 左键 / 右键 | 破坏 / 放置方块（可长按连发） |
| `空格` | 跳跃、游泳上浮、飞行上升 |
| `Shift` | 疾跑 |
| `Ctrl` | 飞行下降 |
| `F` | 切换创造飞行模式 |
| `1-9` / 滚轮 | 选择快捷栏方块 |
| `Esc` | 暂停 / 打开菜单 |

世界是无限生成的；破坏与放置的方块会自动保存到浏览器 `localStorage`，
重新打开页面点击「继续上次冒险」即可回到原处。

## 已实现特性

- **程序化世界**：可播种噪声地形（平原、山脉、海洋、沙滩、洞穴）、树木、海洋
- **体素渲染**：按区块构建并剔除隐藏面的 BufferGeometry，程序生成 16×16 像素纹理图集，
  带环境光遮蔽（AO）平滑光照，透明水、玻璃与树叶
- **物理**：AABB 分轴碰撞、重力、跳跃、游泳、飞行、疾跑
- **交互**：DDA 体素射线检测、目标方块高亮边框、快捷栏
- **环境**：昼夜循环、太阳/月亮、随风飘动的云、天空渐变与雾、水下滤镜
- **音效**：WebAudio 程序合成的破坏/放置音效
- **存档**：种子、全部修改、玩家位置/朝向与时间

```

├── index.html           入口页面与 HUD

├── js/

│   ├── world.js         方块定义、地形生成、区块网格、射线检测、存档

```

## 技术说明

- 区块大小 16×16，世界高度 80；默认视距 4 个区块，远处由雾平滑隐藏。
- 方块修改保存在 `chunkDiffs` 中，区块重新生成时自动重放，跨区块边界自动重建相邻网格。
- 无外部图片、字体或音频资源；像素纹理与音效均由 Canvas / WebAudio 在运行时合成。
